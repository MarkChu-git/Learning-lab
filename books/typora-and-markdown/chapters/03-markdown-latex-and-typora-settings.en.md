## What this chapter covers

This chapter is designed as the first fully practical writing chapter in the volume. It brings together three things that beginners usually learn separately, but should actually connect:

- Markdown basic syntax
- LaTeX-style math syntax in Typora
- Typora settings that directly affect writing workflow

## Core themes in the Chinese chapter

1. **Markdown basics as document structure**
   - headings
   - paragraphs and line breaks
   - ordered and unordered lists
   - blockquotes
   - code blocks
   - links and images
   - tables
   - inline emphasis as secondary structure

2. **LaTeX formula basics in Typora**
   - inline math
   - display math blocks
   - fractions, superscripts, subscripts
   - sums, integrals, square roots, scalable brackets
   - aligned multi-line formulas
   - the idea that formulas are not magic, but structured notation

3. **Typora settings that matter for real writing**
   - Markdown-related preferences
   - inline math and math-related options
   - image handling behavior
   - outline and file tree workflow
   - shortcut learning priorities

4. **Image placeholders prepared in advance**
   - the Chinese chapter explicitly marks where screenshots or diagrams should be inserted,
   - and gives a suggested filename plus the intended explanatory role of each image.
