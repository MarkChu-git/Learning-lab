# Typora and Markdown

> Language / 语言：[中文](README.md) | **English**

This is the first volume in the textbook collection.

Its goal is not to reduce Markdown to a syntax cheat sheet, and not to turn Typora into a simple software recommendation. Instead, this volume is meant to explain the following core questions in a systematic way:

- Why write documents this way?
- Why do so many people learn the syntax but still fail to write well?
- What exactly does Typora solve in this workflow?

For that reason, the volume covers concepts as well as workflow; syntax as well as specification differences; software features as well as the habits that actually determine the quality of long-term writing.

## Who this volume is for

This book is mainly written for three groups of readers:

- **Group 1**: people who have never seriously learned Markdown, but already know they need a more stable writing method.
- **Group 2**: people who know a bit of Markdown, but still keep running into trouble with formatting, paths, export behavior, and cross-platform compatibility.
- **Group 3**: people who want to use Typora as a long-term tool for structured writing and knowledge organization, not just as “an editor that can type Markdown.”

## Scope

This volume will gradually cover the following topics:

1. The design philosophy of Markdown and its writing mindset.
2. Typora’s basic interface, input model, and writing experience.
3. The relationship among Markdown, CommonMark, GitHub Flavored Markdown, and Typora’s supported feature set.
4. Core writing patterns for headings, paragraphs, lists, blockquotes, code blocks, links, images, tables, footnotes, and formulas.
5. Image paths, relative paths, directory structure, file naming, and document organization.
6. YAML front matter, export, PDF/HTML output, and GitHub rendering differences.
7. How to move from writing a single document to maintaining a long-term textbook or knowledge base.

At the current stage, the top priorities are:

- to continue expanding Chapter 1 into real textbook prose,
- to use that chapter to establish the writing standard for the whole volume,

In other words, the immediate goal is not to hang many empty titles, but to make the opened material solid.
