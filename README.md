# Typora 与 Markdown 教程仓库

这个仓库用于持续编写一套偏“教材化”的中文教程，主题围绕 Markdown 写作、Typora 使用方法、文档组织、知识管理与发布流程展开。

整套内容的目标不是做一份速查表，而是从零开始，把“为什么这样写、这样写会发生什么、什么场景该这样写、什么错误最常见、如何形成稳定工作流”讲清楚。阅读完每一章之后，读者应该能够真正上手，而不是只记住几个零散语法片段。

## 写作原则

本仓库的教程采用以下原则。

第一，尽量以循序渐进的方式讲解。先解决“这是什么”，再解决“怎么做”，最后解决“为什么这样做更好”。

第二，尽量避免把正文写成密密麻麻的 bullet point。必要时会使用编号和列表，但主要内容仍以连贯段落展开，让读者能像读一本入门教材那样顺着读下去。

第三，尽量基于原始资料而不是二手转述。与 Markdown 基础语法相关的部分，主要参考 John Gruber 的原始 Markdown 语法说明、CommonMark 规范思路和 Markdown Guide 的兼容性建议；与 Typora 相关的部分，主要参考 Typora 官方支持文档中的语法、图片、数学公式等说明。
